## Keyboard shortcuts

These are the default shortcuts. All of them can be changed under [Settings › Keyboard shortcuts](settings.html#keyboard-shortcuts). On a Mac, use <kbd>Cmd</kbd> instead of <kbd>Ctrl</kbd>.

### Tools

| Tool | Key |
|---|---|
| Select | <kbd>V</kbd> |
| Pen | <kbd>P</kbd> |
| Pencil | <kbd>N</kbd> |
| Eraser | <kbd>E</kbd> |
| Shape | <kbd>S</kbd> |
| Eyedropper | <kbd>I</kbd> |
| Text | <kbd>T</kbd> |
| Nudge | <kbd>U</kbd> |
| Slice | <kbd>K</kbd> |
| Points | <kbd>A</kbd> |

### Editing, view and file

| Action | Keys |
|---|---|
| Undo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
| Delete selection | <kbd>Delete</kbd> |
| Select all | <kbd>Ctrl</kbd>+<kbd>A</kbd> |
| Zoom in | <kbd>Ctrl</kbd>+<kbd>=</kbd> |
| Zoom out | <kbd>Ctrl</kbd>+<kbd>-</kbd> |
| Reset view | <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| Zen mode on and off | <kbd>Esc</kbd> |
| Show or hide layers | <kbd>L</kbd> |
| Export | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Save now | <kbd>Ctrl</kbd>+<kbd>S</kbd> |

### Fixed keys

<kbd>Backspace</kbd> always deletes the selection, or the selected points when the Points tool is active, in addition to the shortcut above. In number fields and when renaming a layer, <kbd>Enter</kbd> confirms and <kbd>Esc</kbd> cancels. In the gallery, holding <kbd>Alt</kbd> (<kbd>Option</kbd> on a Mac) turns 'New Project' into the quick start.

## Touch gestures

| Gesture | Effect |
|---|---|
| Two fingers, move | Pan |
| Two fingers, pinch or spread | Zoom |
| Two fingers, turn | Rotate the canvas |
| Two-finger tap | Undo (adjustable) |
| Three-finger tap | Redo (adjustable) |
| Quick pinch with the fingers almost closing | Reset the view (adjustable) |
| Double-tap a text with the Select tool | Edit the text |
| Long-press 'Reset view' | Reset only pan, zoom or rotation |
| Long-press 'New Project' | Quick start a project with a random name |
| Long-press a project card | Start selecting several projects |

The one-, two- and three-finger double-tap and a quick wide spread can be given an action too. See [Settings › Gestures](settings.html#gestures).

## Mouse and trackpad

| Input | Effect |
|---|---|
| Scroll wheel | Zoom around the pointer |
| Drag with the middle button | Pan |
| Trackpad pinch, two-finger swipe, two-finger turn | Zoom, pan, rotate |
| Right-click on the canvas | Context menu |
| Right-click on 'Reset view' | Reset only pan, zoom or rotation |
| Right-click on a project or folder card | Card menu |
