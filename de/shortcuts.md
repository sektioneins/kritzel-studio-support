## Tastenkürzel

Das sind die Standard-Tastenkürzel. Alle lassen sich unter [Einstellungen › Tastenkürzel](settings.html#tastenkuerzel) ändern. Die App beschriftet die Taste <kbd>Strg</kbd> mit „Ctrl“. Auf dem Mac verwenden Sie <kbd>Cmd</kbd> statt <kbd>Strg</kbd>.

### Werkzeuge

| Werkzeug | Taste |
|---|---|
| Auswahl | <kbd>V</kbd> |
| Stift | <kbd>P</kbd> |
| Bleistift | <kbd>N</kbd> |
| Radierer | <kbd>E</kbd> |
| Form | <kbd>S</kbd> |
| Pipette | <kbd>I</kbd> |
| Text | <kbd>T</kbd> |
| Verschieben | <kbd>U</kbd> |
| Schneiden | <kbd>K</kbd> |
| Punkte | <kbd>A</kbd> |

### Bearbeiten, Ansicht und Datei

| Aktion | Tasten |
|---|---|
| Rückgängig | <kbd>Strg</kbd>+<kbd>Z</kbd> |
| Wiederholen | <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>Z</kbd> |
| Auswahl löschen | <kbd>Entf</kbd> |
| Alles auswählen | <kbd>Strg</kbd>+<kbd>A</kbd> |
| Vergrößern | <kbd>Strg</kbd>+<kbd>=</kbd> |
| Verkleinern | <kbd>Strg</kbd>+<kbd>-</kbd> |
| Ansicht zurücksetzen | <kbd>Strg</kbd>+<kbd>0</kbd> |
| Zen-Modus ein und aus | <kbd>Esc</kbd> |
| Ebenen ein- und ausblenden | <kbd>L</kbd> |
| Exportieren | <kbd>Strg</kbd>+<kbd>E</kbd> |
| Sofort speichern | <kbd>Strg</kbd>+<kbd>S</kbd> |

### Feste Tasten

Die Rücktaste löscht immer die Auswahl, beim Werkzeug „Punkte“ die ausgewählten Punkte, zusätzlich zum Kürzel oben. In Zahlenfeldern und beim Umbenennen einer Ebene bestätigt <kbd>Enter</kbd>, <kbd>Esc</kbd> bricht ab. In der Galerie macht gedrückt gehaltenes <kbd>Alt</kbd> (auf dem Mac die Wahltaste) aus „Neues Projekt“ den Schnellstart.

## Touch-Gesten

| Geste | Wirkung |
|---|---|
| Zwei Finger bewegen | Verschieben |
| Zwei Finger zusammen- oder auseinanderziehen | Zoomen |
| Zwei Finger drehen | Leinwand drehen |
| Zwei-Finger-Tippen | Rückgängig (einstellbar) |
| Drei-Finger-Tippen | Wiederholen (einstellbar) |
| Schnelles Zusammenziehen, bis sich die Finger fast berühren | Ansicht zurücksetzen (einstellbar) |
| Text mit dem Auswahlwerkzeug doppelt antippen | Text bearbeiten |
| „Ansicht zurücksetzen“ gedrückt halten | Nur Verschiebung, Zoom oder Drehung zurücksetzen |
| „Neues Projekt“ gedrückt halten | Schnellstart eines Projekts mit Zufallsnamen |
| Projektkarte gedrückt halten | Mehrfachauswahl starten |

Auch das Doppeltippen mit einem, zwei oder drei Fingern und ein schnelles, weites Auseinanderziehen lassen sich mit einer Aktion belegen. Siehe [Einstellungen › Gesten](settings.html#gesten).

## Maus und Trackpad

| Eingabe | Wirkung |
|---|---|
| Mausrad | Zoomen um den Mauszeiger |
| Ziehen mit der mittleren Maustaste | Verschieben |
| Trackpad: zwei Finger zusammenziehen, wischen, drehen | Zoomen, verschieben, drehen |
| Rechtsklick auf die Leinwand | Kontextmenü |
| Rechtsklick auf „Ansicht zurücksetzen“ | Nur Verschiebung, Zoom oder Drehung zurücksetzen |
| Rechtsklick auf eine Projekt- oder Ordnerkarte | Menü der Karte |
